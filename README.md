# 旅行精算ツール

旅行中に各参加者が立て替えた費用から、「誰が誰にいくら渡せばよいか」を計算する割り勘ツールです。
ビルド不要の静的サイト（HTML / CSS / JavaScript）で、入力内容はブラウザの localStorage にのみ保存されます。

## 仕様（確定版）

### 計算ロジック（`settle.js`）
1. 合計金額 ＝ 全参加者の支払額の合計
2. 一人あたりの金額 ＝ 合計 ÷ 人数（**1 円単位で切り上げ**）
3. 差額 ＝ 支払額 − 一人あたりの金額（＋は受け取る側、−は渡す側）
4. 切り上げで多く集まる端数は、**最も多く支払った人**が受け取る
5. 渡す側・受け取る側をそれぞれ金額の大きい順に突き合わせて精算を作る（受け渡しは最大「人数 − 1」回）

### 入力画面（`#/`）
- 参加者ごとに名前を入力できる（最大 20 文字）。未入力の場合は「参加者1」「参加者2」…と自動で表示
- 参加者は初期 2 名、「参加人数を追加」で追加、2 名を超えると削除可
- 1 人あたり「買ったもの」「金額」の 2 カラム × 初期 3 行（「行を追加」で追加、行ごとに削除可）
- 参加者ブロックは開閉できる
- 金額欄は `inputmode="numeric"` で数字キーボードを表示。全角数字・カンマは自動で半角化し、数字以外は除去
- 入力のたびに localStorage に自動保存
- 「入力をリセットする」→ 確認モーダル →「削除する」で初期状態に戻す
- 金額が 0 円のまま「精算する」を押すとエラーを表示

### 結果画面（`#/result`）
- 旅費合計、一人あたりの金額、誰が誰にいくら渡すか、各人の支払済み金額（過不足つき）
- 「結果をコピーする」：LINE などに貼り付けられるテキストをクリップボードにコピー
- 「戻る」：入力画面に戻る（入力内容は保持）

### 注意事項
- データは**その端末・そのブラウザにのみ**保存されます。1 台の端末でまとめて入力する使い方を想定しています
- 買ったもの欄のキーボード種別は端末の設定に従います（Web からひらがなキーボードを指定することはできません）

## ファイル構成

```
index.html             画面の骨組み・ホーム画面アイコン用タグ
styles.css             スタイル（冒頭の :root 変数で色・フォントを定義）
settle.js              精算ロジック（DOM 非依存）
app.js                 画面描画・入力・保存・ルーティング
manifest.webmanifest   Android 向けホーム画面設定
icons/                 アイコン（現在は仮）
```

## ローカルでの確認

```bash
python3 -m http.server 8430
```

ブラウザで http://localhost:8430 を開きます。

## 差し替え予定

- **アイコン**：`icons/` 内の同名ファイル（`icon-180.png` / `icon-192.png` / `icon-512.png` / `icon.svg`）を置き換える
- **デザイン**：`styles.css` 冒頭の `:root` 変数を中心に変更する（現在のトーンは仮）

## GitHub Pages での公開

1. このディレクトリを GitHub リポジトリとして push する
2. リポジトリの Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` に設定
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される（パスはすべて相対指定のため、サブパスでも動作します）
